# Your Claude API key

Health Review uses no AI until you add your own Claude API key. With a key, it writes your weekly review every Sunday morning and answers questions in the Next program chat. Anthropic bills you directly for that use; a weekly review usually costs well under a dollar.

## Get a key

- Create an account at [console.anthropic.com](https://console.anthropic.com), add a payment method or credits, and create an API key under **API keys**. Anthropic's own instructions: [Getting started](https://docs.claude.com/en/api/getting-started).
- The key starts with `sk-ant-`. Copy it once; Anthropic shows it only when it is created.

## Add it

- In Health Review, open **Settings** and paste it under **Claude API key**, then **Save key**. Health Review checks it with Anthropic first (free).
- It is stored encrypted and never shown again, not to you and not on any screen the app's operator has. Only your own review and chat use it.
- **Remove key** turns the AI off again. You can also delete the key in Anthropic's console at any time.

## What is sent to Claude

- Computed summaries of your data (averages, changes, statuses), never raw exports, and your own notes for the week.
